# K-Drama-Recommender-Chatbot
AI-powered K-Drama recommendation chatbot using Google Gemini API and Python.

Features
- Recommends 2-5 South Korean dramas based on user preferences.
- Provides drama titles, release years and summarises.
- Explain why each recommendation matches the user's interests.
- Supports interactive conversations and follow-up questions.

Technologies Used
- Python
- Google Colab
- Google Gemini API (Gemini 2.5 Flask)

How to Run
- Open the notebook in Google Colab.
- Install the required dependencies.
- Configured your Gemini API key.
- Run the notebook cells.
- Start chatting with K-Dramabot!
